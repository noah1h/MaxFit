== Description ==
MaxFit is a sleek, responsive, and user-friendly HTML template designed for modern gyms, fitness centers, personal trainers, and wellness clubs. Packed with essential features like membership plans, class schedules, nutrition calculators, trainer profiles, and FAQs, MaxFit helps fitness businesses build a bold online presence that motivates and converts.

Built with clean code and modern UI components, MaxFit ensures smooth performance across all devices. Whether you're launching a new fitness brand or revamping your existing gym website, MaxFit is the perfect fit.

== Installation ==
1. Unzip the downloaded file  
2. Open the /MaxFit folder  
3. Launch `index.html` in your browser  
4. Open `/documentation/documentation.html` for full setup guidance

== Dependencies ==
- Bootstrap 5 – https://getbootstrap.com  
- jQuery 3.7.1 – https://jquery.com  
- AOS (Animate On Scroll) – https://michalsnik.github.io/aos/
